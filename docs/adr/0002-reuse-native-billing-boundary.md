# 复用固定原版计费契约，缺能力时明确拒绝

既有批准选择复用官方原版 new-api rc.50 的表达式、已有任务插件/计量输入及原生版本化配置接口，而非改核心、扩插件、增加业务代理或第二套扣费。这样让价格源只承担官方资料、CNY 基础价、固定候选与受控读回；代价是原版不能完整表达的收费条件必须保留排除状态，而不是用部分价格成功、均价或新计量层补齐。

模型、任务插件和工具价格分区分别处理；工具全表写入没有原生 CAS，跨分区不承诺全局原子性，实际工具应用需要独占窗口。依据：[批准 Spec 快照](../requirements/snapshots/spec-v0.12.md) §2、§4—5、[已审 stg 方案](../stg/CNY-INTEGRATION-ACCEPTANCE.md)；这不是新网关能力或生产应用授权。
