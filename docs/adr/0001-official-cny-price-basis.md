# 以官方原始价目建立 CNY 基础价

既有批准选择官方基准价，而非采购线路成交价作为对客基准：适用国产原始 CNY 保持，国外原始 USD 固定乘 7 一次；站内显示与配额口径保持批准值，分组倍率由运营独立配置。选择这一边界是为了避免把已舍入的估算 USD 逆算成原价、混留不同币种的收费项或将采购优惠误当对客政策；日后改变它将影响整套价格资料、确认身份与账单解释。

依据：[批准 Spec 快照](../requirements/snapshots/spec-v0.12.md) §1—2、[来源权威规则](../requirements/CNY-SOURCE-REGISTRY.md)。本文记录已确认选择及理由，不另维护一份价格政策。
