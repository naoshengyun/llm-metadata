## 对身份与时效的两个明确结论

1. **Kimi 中国站新地址有实际跳转证据**，旧域名不是唯一可用入口；但本次官方 Markdown 返回空表，所以正式抓取必须校验 HTML 内动态表，不能只抓 Markdown。新地址也不是授权把中国/国际价格混合。[新价表](https://platform.kimi.com/docs/pricing/chat)、[旧域名入口](https://platform.moonshot.cn/docs/pricing/chat)
2. **Seedance 2.5 已找到确切官方 model 参数**：教程 Model ID 行及请求示例分别给 `doubao-seedance-2-5-260628`，Flash 为 `doubao-seedance-2-5-flash-261115`。这两项不在本次固定上游 `volcengine` 的12条目录中，属于官网新发现与目录范围的差异，不因来源已找到便新增进目录或声称已发布。视频计费基于实际 `usage.completion_tokens`，每秒示例只是特定分辨率/输入/时长下的估算。[官方参数及例子](https://ark.volcengine.com/region:cn-beijing/docs/seedance-2-5)、[实际计价规则](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)

本轮结果：12/12端点都有明确处置；11个找到可读官方适用价格入口（其中Kimi需读取HTML动态表，部分端点仍有旧模型缺价），1个（SenseNova当前端点）价格币种/单位与现行适用性未核实。该计数不是137模型的官方价格覆盖率，也不代表自动同步、解析器或全模型金额校验已完成。
