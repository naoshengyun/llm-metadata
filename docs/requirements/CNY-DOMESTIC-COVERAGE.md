# 国内官方 CNY 核价记录

本次输入是 [#39 统一构建](https://github.com/naoshengyun/llm-metadata/issues/39) 经 [#41 核价入口](https://github.com/naoshengyun/llm-metadata/issues/41) 验证的固定候选 `90cd9054db54c26056fb3a5132928dc71f9c79be2d1dbe4af06b92ab1b647659`（源码 `277d20ec393b14d1fbf711ee3abc9b662d814e7e`，上游 `24d3f35cc82f21bdc2a049888c71af5fb4f4d7b4`）。逐行按该候选的 provider/model 身份冻结，共 147 条模型记录，包含自有任务增补。批量及其他价目身份保留在各行。直接读取的每份官方响应、原始金额、收费条件、核查结果和候选去向见 [逐条矩阵](CNY-DOMESTIC-COVERAGE.tsv)。

## 核价结果

- 固定官方响应成功提取 67 个模型身份下的 70 条价目，包括 Kimi 六条既有标准价。价目结果为 37 条一致、21 条出现收费条件差异、11 条原生能力不足和 1 条未来生效。工具费用保留独立参考，按运营免费规则不进入模型表达式。
- 独立统一候选含 630 条模型记录、125 条订阅记录、255 个可同步键和 88 条自有原价。与固定输入比较，新增 15 个原生键并更新 11 个原生键，包括 MiniMax-M3 标准挂牌价及智谱旧有简化表达式。MiniMax 价表同时列原价和永久五折，按本轮挂牌原价政策保留原价。四条 DeepSeek 官方价完整提取后发现原生时间函数表达不了中国法定节假日闲时，因此以 `native-capability-exclusion` 从候选同步 JSON 中移除四键。目录保留原价、来源、条件和原因。
- 官方核价入口生成的 18 项已选价目条件差异已应用到独立复核目录，统一构建成功。该验证保持义务相关条件可见，产物没有发布或应用到运营实例。
- Seedance 2.5 标准版保留完整官方参考及 [#32 4K 结算验证](https://github.com/naoshengyun/llm-metadata/issues/32) 标记，整个模型仍不进入同步 JSON。七条国内延期模型按 [#35](https://github.com/naoshengyun/llm-metadata/issues/35) 原 ID 处理。
- 余下 72 个非延期、非 #32 模型身份尚无成功的持续核价记录。其中 55 条缺合格价目，17 条仍显示固定上游已选状态。矩阵报告逐条候选状态与核查情况。固定上游旧报价的已选状态不计为本次核查成功。

## 尚缺证据或实现

- 阿里百炼的北京原价和官方上下文缓存文档已经支持三个 Qwen 3.7 型号的隐式与显式价目。其余型号需要逐条验证北京表、缓存例外、模态和分档，涉及音频时长或字符计费的型号还需独立用量契约。
- 火山方舟已核对四条中文在线隐式缓存价目及八条图片和视频任务价目。旧 `doubao-seedream-5-0-260128` 的当前页面缺该精确身份的独立价目，暂保留已有候选。其余上游模型还需核对正式模型版本映射、音频收费和完整阶梯。
- MiniMax 已核对 M3、M3.1 Flash、两条 image-01 价目、H3、H3-Max 和六条语音。H3 候选采用国内视频 API 用量，覆盖 2K、768P、输入视频秒及前五张图片免费。H3-Max 和六条语音已提取价格，尚缺固定原生插件模型绑定或计费字符用量。M2 系旧模型当前公开页未列精确现价或缓存写入。
- 智谱已核对 14 个国内型号，包含官网明确免费及历史保留价目。GLM-4.7、GLM-4.5-Air 的 len 和 c 同时参与低输入、短输出档，与官方边界一致。glm-4.5、glm-4.5-flash、glm-4.6 仍缺精确官方适用价。
- 小米 V2.5 与 V2.5 Pro 的中文永久调价公告仍给出历史人民币图价，现行表缺旧型号，且官方下线公告明确旧 API 键失效。历史原价仍可核查，图片证据的自动数字读取未实现。
- Kimi 的 Batch 和重复上游身份保留在矩阵，现有解析注册覆盖实时标准价。
- 阶跃 SSE ASR 的现价是 0.15 CNY/输入音频小时。后续 0.45 CNY/小时于北京时间 2026 年 11 月 23 日 12:00 生效。原生模型价格缺该用量契约，报告只记录官方证据和未来生效时间。
