## Problem / Solution

只用43条价格记录重建页面目录，会遗漏上游供应商、模型能力、上下文、限额、语言与导航，也把价格就绪错误地当成资料是否存在。恢复固定上游全部catalog/UI/provider/model/i18n，以完整元数据作为目录事实；在独立的CNY价格视图中按已批准规则判断价格资格并转换，显式区分缺价与确实免费。页面保留不代表模型可售；API只输出完整可表达的合格项目，并对全部输入列明去向。

### 用户可观察的结果

1. 能浏览完整供应商及国内/国际/订阅等导航，查看所有模型原有能力字段，而非只有有价条目。
2. 默认使用人民币基础价；清楚看出原始币种/来源，不把CNY展示误称供应商官方以CNY结算。
3. 国产默认国内端点，国际区域资料仍可访问；同名记录不静默覆盖、不混合收费条件。
4. 缺来源或不可表达时保留资料并说明原因，不显示为0、不提供可应用价格。
5. 页面、复制、下载及新API遵循同一固定来源和规范化结果；所有合格价格同步进入新发布，不仍停在43。
6. 旧版本固定链接保持可读且字节不变，新稳定入口可追溯到新版本及选择/排除清单。

## 数据与币种规则（已确认）

| 固定上游价目情况 | CNY处理 | 发布资格 |
|---|---|---|
| 明确 `cost.currency=CNY` | 原金额及原收费结构保留 | 仍需完整性/原生可表达判断 |
| 明确 `currency_options.CNY` sheet | 使用该明确人民币sheet，不从USD估算反推 | 同上，记录选中sheet |
| 国外明确USD sheet | 仅金额字段固定×7一次 | 同上；源USD与归一CNY分别标识 |
| 国内端点只有USD估算、原币种不明或缺cost | 保留全部模型元数据，CNY价格标缺源；不接自有raw43补价、不猜别名、不逆算 | 不输出可应用价，列具体原因 |
| 明确官方数值0且其余收费条件完整 | 保留显式0及来源 | 不能与缺失/null/估算混同，仍须可表达 |
| 订阅或其他当前原生无法完整表达的形状 | 原资料与价格说明可保留 | 不伪装成普通倍率价，标不支持/排除 |

不能凭厂商国籍给每条cost猜币种；地区选择与币种证据分开。金额白名单覆盖嵌套缓存写入/读取、TTL档、tiers、schedule和模态收费金额，不限顶层input/output；数量阈值、上下文/输入输出limits、TTL时长、倍率、时间边界和能力参数不乘7。收费条件或金额叶子无法判定时列为明确不支持，不裁掉难表达部分后冒充完整价格。源字段/原始值保持可追溯，派生CNY视图不能破坏原元数据。

## 元数据、页面与日期

完整保留50 providers、616 Model记录及全i18n结构：名称/描述、context、input/output modalities、limits、能力字段、provider说明和所有原有字段；包括当前不用作价格导出的资料。导航保留订阅和区域，国产默认国内，仅作与CNY默认契约一致的最小适配。原搜索/分类/卡片/表格/详情/语言/主题/复制下载尽量复用，不再以自有quote重建目录。

元数据 `last_updated` 等日期按上游原义保存；核价/价格来源日期单独记录，缺失时诚实标无提供。git固定时间、生成时间、导入时间不是官网核价时间，不用checkedAt覆盖last_updated。CNY基础价标签与真实供应商结算币种分开；不继承上游7.3换算配置去覆盖用户本次固定×7规则，也不新增可变汇率业务。

## API资格集合与同名地区选择

先按固定provider+model+端点/区域+源sheet确定价目身份，保留原收费形状，再得到可表达CNY项目。导出为原生键前显式记录区域选择与去重规则：国产默认国内，国际同名仍是独立资料；不沿用国际billing.priority自动抢占，不合并两个端点cost。每个重复键组必须有选中项及其他项排除理由和来源定位；不能以输入遍历顺序决定。已确认国内默认无法解决的实质歧义以具体冲突列表交486，不自行猜价/裁剪，其他确定部分继续。

全部合格API项等于“按上述规则选定且收费完整、原生可表达”的集合，不等于全部616模型，也不等于旧43选择。输出全量选中/缺价/不支持/区域重复等清单，使每条原目录记录有可追溯去向；清单必须区分价目条目、provider-model记录、原生键数。页面缺价可见但复制/下载/API不得将其当成可应用值；对于API覆盖范围，页面可复制的原生mode/expr与同版API精确相符。无资格项目不出价，不虚构免费。
