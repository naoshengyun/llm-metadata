# T3 — Official task media prices to existing plugin usage prices

Status: implemented locally; independent review and native-instance I validation pending.
Depends on T1. Scope and AC references: approved Spec v0.12 sections 3–7; T3 from `2026-11-16-脑生云统一CNY定价-候选任务拆解草稿.md`. AC-08(D conditions), 18, 26(D), 28(D), 30(D).

Implementation: `src/cny/media.ts` exports `compileTask(TaskQuote)`; `native-task-schema.ts` pins official new-api rc50 `f2aa91232ed3e5878a614762ace6736a2b74257f`. The fixture was extracted read-only from each existing `plugins/tasks/*/plugin.js` metadata using a network-free Node VM, retaining declared models, numeric units, enum/boolean fields, per-model usageProfiles, source path and plugin version. Plugins without task models/usageSchema are omitted. Eleven existing task plugins are represented; unknown bindings are unsupported, never new plugins.

Contracts: input rates are original CNY/USD. CNY is retained; USD is multiplied by 7 exactly once at compile time. Task output is CNY/request; token terms explicitly divide by 1000000. Numeric usage keys and units must match the selected complete model profile. Every numeric usage category needs a finite nonnegative price, explicit zero/free, or a nonempty `notApplicable` reason. Conditional tiers use declared enum/boolean facts and end in an unconditional fallback; unsupported arithmetic/meter shapes are rejected. Task prices remain a separate model→plugin→expression partition at integration.

Evidence: `tests/cny-media.test.mjs` tests 1, 2, 3, 5 and 6 were added in vertical red→green slices. Initial token test failed on missing module; missing-key/unit test failed because the skeleton returned ready; enum test failed on unsupported tiers; missing-fee test failed because an incomplete image quote returned ready. Native ceiling test rejected rates whose arithmetic would overflow the host smoke vectors. Each then passed after minimal implementation. Final command: `node node_modules/typescript/bin/tsc --outDir .cache/cny-build && node --test tests/cny-media.test.mjs`: 6/6 tests pass (including T4). Deterministic G/S compiler contracts only. No actual native parser, API or paid supplier call was run here; I and real usage/settlement remain unverified.
