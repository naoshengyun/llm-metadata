## Implementation

`src/cny/apply.ts` exports `NativePricingAdapter`, `previewArtifact`, `applyArtifact`.

- Fixed artifact integrity is verified before preview and application using T6 `verifyArtifact`.
- Preview identity binds artifact contents, target origin, explicit selected model/plugin/tool keys, and configuration snapshots. Confirmation must carry that identity, artifact identity, same target, explicit `confirmed`, and a nonempty runtime actor. Native authentication/authorization is supplied by the caller's fetch implementation and enforced by the native server; the actor label is an audit identity, not a replacement credential.
- Target `USDExchangeRate=1` and `QuotaPerUnit=500000` are read and required before writing. Neither setting nor group multipliers is written.
- rc50 `GET/PATCH /api/option/model_pricing` uses complete per-model drafts, dotted option names, and `expected_version`. Unselected configured fields and plugin variants survive. Plugins use each model's plugin→expression object, never flat storage keys.
- Tools use `GET /api/option/` then `PUT /api/option/` with `tool_price_setting.prices` JSON string. A fresh full-map read preserves unselected keys changed after preview; a selected key changed after preview conflicts. Full-map native tool writes have no server-side compare-and-swap. Concurrent-writer preservation between the last read and PUT is unsupported by this native API: the adapter cannot guarantee preservation in that window and does not claim global atomicity. Use an externally controlled exclusive update window when applying tool prices.
- Every attempted write is followed by readback, including thrown timeout and native failure. Readback success can resolve a timed-out commit. Conflict never force-retries. Failure/mismatch/unknown remain visible per selected item; no automatic rollback.
