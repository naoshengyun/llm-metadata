# Exa MCP quota policy

- Exa has a limited paid monthly quota. Do not use it for routine discovery or ordinary searches.
- Use Exa only to verify high-value, current external facts when local code, provided material, or primary official sources are insufficient.
- When Exa is necessary, narrow the query and request the minimum useful number of results and content tokens.
